# Requirements

## Functional Requirements

### FR-01
The system must accept a job description as input.

### FR-02
The system must extract required skills.

### FR-03
The system must compare job requirements
with candidate skills.

### FR-04
The system must generate a match score.

### FR-05
The system must provide a recommendation.

### FR-06
The system must save the analysis result.

## Non-Functional Requirements

### NFR-01
The system should return structured JSON output.

### NFR-02
The system should handle invalid input gracefully.

### NFR-03
API credentials must not be committed to GitHub.
